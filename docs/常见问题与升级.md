# 常见问题与升级

## 下载后只有两个 ZIP，正常吗？

正常。仓库提供两个分发包和在线文档。下载整个仓库后，还需要解压所选 B 或 C 包。

## 如何核对完整性？

与同一版本 `SHA256SUMS.txt` 中的 SHA256 比较。Windows PowerShell：

```powershell
Get-FileHash -LiteralPath '.\B-DSH版.zip' -Algorithm SHA256
Get-FileHash -LiteralPath '.\C-通用平台版.zip' -Algorithm SHA256
```

具备 `sha256sum` 的环境，在仓库目录执行：

```bash
sha256sum -c SHA256SUMS.txt
```

macOS 可用：

```bash
shasum -a 256 'B-DSH版.zip' 'C-通用平台版.zip'
```

忽略十六进制字母大小写，其他字符必须一致。不一致时重新获取同一版本的 ZIP 与校验文件，不能用旧校验值核对新包。

## B 技能没有出现

确认宿主支持的技能格式与根目录，检查 `paper-repro-pipeline/SKILL.md` 没有多嵌套一层，以及是否读取了别处的旧副本。按宿主要求刷新或重开会话。

无法确认兼容性时用 C 版。文件存在不等于宿主注册，注册也不等于模型一定遵守指令。

## 为什么参考目录没显示为技能？

本包 `ai-research-reproduction/` 只有五份参考文件，没有完整技能定义。它供编排技能直接读取，不必显示为独立技能。

## 五份纪律文件找不到，可以跳过吗？

B 版不可以。确认它们在与 `paper-repro-pipeline/` 同级的 `ai-research-reproduction/references/`，读取路径相对于技能目录解析。修复后继续。

C 版没有这项外部文件安装要求。切换时使用整套 C 文件，不要只删 B 的门禁。

## 找不到速查卡

确认 Agent 当前工作区是论文项目根目录，`<工作区根目录>` 已替换。方法论放在别处时使用真实路径，再做只读验收。

## 已有 AGENTS.md 或完整同名技能怎么办？

先备份、比较、合并，不覆盖整个文件或目录。保留项目路径和约定；B 包的参考材料不能替代完整同名技能。

## C 版上传后好像没读到

要求列出实际可访问文件并定位具体章节。受资料检索或上下文限制时按阶段提供内容，不能只凭“我读过了”验收。

## 精简提示词能代替完整手册吗？

不能。提示词保留核心约束，手册提供详细步骤与案例。至少保证当前阶段的详细章节可读。

## 能自动跑所有论文吗？

不保证。代码、数据、依赖、硬件与规格需要分别核对。理论或专用硬件实验需要特定验证方案；没有运行工具的会话只能提供分析与执行计划。

## 能自动安装所有外部技能吗？

本仓库没有外部技能一键安装器，也未捆绑映射表中的全部增强技能。B 必需的五份参考文件已经包含；可选增强缺失时依照映射表和方法论执行。

## 官方仓库不可用，直接自实现吗？

取决于任务授权。允许自实现时评估 L2；限定官方仓库时记录阻断。应在任务指令中写明限制，不能仅凭 `L1-blocked` 标签自行扩大范围。

## B 和 C 能一起加载吗？

建议一个项目用一套主规则。两版加载契约与修订进度有差异，混用容易引入冲突。更换后重新验收，避免旧资料仍被检索。

## 如何升级？

1. 备份本地改动，尤其是路径和工作区约定。
2. 在新目录解压。
3. B 一起比较技能、方法论、参考文件与模板；C 一起更新手册和提示词。
4. 合并本地配置，重新检查路径与实际读取能力。
5. 报告、代码、数据、结果和过程记录独立保留。

不要在 ZIP 内维护定制副本；保留解压后的工作副本并注明对应版本或提交。

## 如何反馈？

提供版本（B/C、提交号或 ZIP 校验值）、系统和 Agent 宿主、目录布局、最小提示词、期望与实际行为。执行过代码时附对应命令和相关日志。

个人用户名可隐去，账号凭据无需提供。明确问题发生在下载、路径、加载、规则执行还是实验阶段，更便于定位。
