# 通用资料使用说明

这份资料包与技能安装使用同一套源文件自动生成，不是独立维护的 C 版本。

## 文件

- `论文复现工作流-通用手册.md`：入口、方法论、五份纪律资料与模板，按“资源”章节查阅。
- `系统提示词-精简版.txt`：由 SKILL.md 正文生成的指令。
- `README-怎么用.md`：本说明。

## 怎么用

1. 解压 `universal.zip`（旧下载名 `C-通用平台版.zip` 也是相同文件）。
2. 将完整手册提供给能读取资料的会话或项目。
3. 将精简指令放入可用的指令入口，没有入口时先在对话中粘贴。
4. 提供论文、目标、已有结果、本轮执行范围和预算。
5. 先做只读验收：要求列出实际可读资料，定位“全局执行范围”和代码可用性规则。

环境有上下文或检索限制时，按阶段提供相关“资源”章节。资料上传成功不等于模型已经读过全部内容。

五份纪律资料已经合并在完整手册里，不需要另外安装插件或外部技能。所需章节不可读时应说明缺失，不能凭记忆声称加载成功。

## 初次任务

```text
请按提供的完整手册核对这篇论文。
本轮只读，不安装、不运行代码或训练。
列出实际可读资料、目标实验、参数与出处，
判断官方代码线索是否已核实，提出最小验证计划。
未执行和未验证项单独标记。
```

后续执行时明确允许的命令、环境、数据与资源预算。没有运行工具的环境只提供分析和本地执行步骤，不把示例输出写成实测结果。

## 续接与升级

换会话时提供当前手册、任务范围、已执行命令与日志、已验证结果、未决项和剩余预算。

升级时同时替换手册与提示词，移除资料区旧副本；自己的代码、报告和记录独立保留。两种接入方式的研究规则相同，无需同时加载两份入口。
