# 安装、更新与卸载

统一入口名为 `paper-repro-pipeline`。当前包自带方法论与五份纪律资料，不需要再安装 `ai-research-reproduction` 或复制方法论到论文工作区。

## 1. 准备

在论文项目目录操作。使用 npx 时确认：

```bash
node --version
npm --version
git --version
```

本轮测试安装器为 `skills@1.7.2`，其 npm 元数据声明 Node.js `>=22.20.0`。安装器需取得 npm 包和 GitHub 仓库，网络及 Git URL 重写设置可能影响下载。

## 2. 查看与安装

```bash
npx skills add 1345400660-debug/science-reproducibility-skill --list
npx skills add 1345400660-debug/science-reproducibility-skill --skill paper-repro-pipeline
```

第一条只列出技能；第二条安装，由安装器选择或询问宿主和范围。自动检测和交互行为取决于当前环境。

可选参数（针对已测试安装器）：

| 参数 | 意义 |
|---|---|
| `--agent <宿主标识>` | 指定目标 Agent；以安装器支持的标识为准 |
| `--global` | 用户级安装，供多个项目使用 |
| `--copy` | 使用复制模式，减少符号链接权限问题 |
| `--yes` | 跳过交互确认；先明确宿主和范围再使用 |
| `--list` | 仅发现技能，不安装 |

需要重现测试版本时，把 `npx skills` 换成 `npx skills@1.7.2`。本仓库不是自有 npm CLI，不能通过 `npx science-reproducibility-skill` 安装。

## 3. 手动安装

下载 `paper-repro-pipeline.zip`，在新的目录解压。Windows PowerShell：

```powershell
Expand-Archive -LiteralPath '.\paper-repro-pipeline.zip' -DestinationPath '.\skill-unpacked'
```

把其中整个 `paper-repro-pipeline/` 复制到宿主支持的技能根目录。对于支持项目级 `.agents/skills/` 的宿主，示例如下：

```text
论文项目/
└── .agents/skills/paper-repro-pipeline/
    ├── SKILL.md
    ├── references/
    │   ├── workflow.md
    │   ├── agent-operating-principles.md
    │   ├── research-rigor-principles.md
    │   ├── deep-learning-experiment-principles.md
    │   ├── research-safety-principles.md
    │   └── research-pitfall-checklist.md
    └── templates/
        ├── task-prompts.md
        └── AGENTS.md
```

其他宿主使用其实际支持的目录。不要只复制 `SKILL.md`。已有同名技能先备份本地修改；不覆盖不相关的技能或工作区约定。

无需替换工作区占位符；全部方法论链接在技能目录内。`templates/AGENTS.md` 是可选模板，只在需要时合入现有约定。

## 4. 验收

使用安装器可查看安装记录：

```bash
npx skills list
```

还需让目标 Agent 实际读取资料：

```text
只读验收 paper-repro-pipeline，不安装、不运行论文代码。
请列出实际读取的入口、方法论和五份纪律资料，
给出方法论“全局执行范围”与阶段1.4各一个可定位要点。
确认资料都来自同一个安装目录，报告不可读或未验证项。
```

文件被安装、宿主能发现、模型能读取并正确遵守，是不同层次。仅安装器成功退出不足以证明所有层次通过。

## 5. 更新与卸载

先备份安装目录里的定制修改，检查新版本说明。更新指定技能：

```bash
npx skills update paper-repro-pipeline
```

根据提示选择范围；用户级更新可加 `--global`。更新后重新验收，保存的论文项目、报告、数据和日志不作为安装包替换对象。

卸载项目级技能：

```bash
npx skills remove paper-repro-pipeline
```

用户级卸载加 `--global`。手动安装则先确认宿主路径，再移走该技能目录；不要删除整个技能根目录或同名外部参考仓库。

## 6. 排障

- `npx` 找不到：检查 Node.js/npm 安装和 PATH。
- Node 版本不符合：按所选安装器版本的 engines 要求更新。
- GitHub 克隆失败：检查网络、代理和 Git `insteadOf` 设置；可以先下载 ZIP 手动安装。
- 显示没有技能：确认下载的是当前仓库版本，里面有 `skills/paper-repro-pipeline/SKILL.md`。
- 找不到参考文件：应完整安装同一技能目录，旧版本的兄弟目录依赖已取消。
- 宿主仍读旧版：确认项目级/用户级优先级与实际读取路径，按宿主方式刷新会话。

本说明不承诺所有宿主自动识别，也不会自动安装论文运行依赖。
