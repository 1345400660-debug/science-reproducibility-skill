# C 通用版使用说明

适用于 `C-通用平台版.zip`。无需安装外部技能，可供 Agent 读取，也可由研究者人工按章节执行。

## 1. 解压与检查

| 文件 | 用途 |
|---|---|
| `README-怎么用.md` | 本说明 |
| `论文复现工作流-通用手册.md` | 完整阶段、方法和历史案例 |
| `系统提示词-精简版.txt` | 常驻核心约束，不能代替完整手册 |

Windows PowerShell，在 ZIP 所在目录执行：

```powershell
Expand-Archive -LiteralPath '.\C-通用平台版.zip' -DestinationPath '.\C-workflow'
```

其他系统使用归档管理器，或在具备 `unzip` 时执行：

```bash
unzip 'C-通用平台版.zip' -d C-workflow
```

使用新的解压目标。安装 C 包不需要 `pip install` 或环境变量；论文运行环境在规格核对后另行准备。

## 2. 选择接入方式

### 支持项目资料与指令的环境

1. 创建论文项目或工作空间。
2. 将完整手册作为可读取的资料。
3. 将精简提示词完整放入项目指令或自定义指令区域。
4. 提供论文和任务说明。
5. 用第 3 节确认当前会话实际能读取文件。

平台入口、资料大小限制与检索行为各异。全文不可见时按阶段提供章节；上传成功不等于模型已阅读全文。

### 普通对话

先粘贴精简提示词，再上传手册。不支持附件时，先粘贴速查卡和当前阶段章节；进入下一阶段前再补相应内容。

换新会话时重新提供资料与状态摘要，不能假设新会话能访问旧附件。

### 本地 Agent

将三个文件放入工作区固定位置，提供完整路径，要求先读提示词与当前阶段手册。无需把 C 版改名为 `SKILL.md`。执行、联网和文件访问以当前环境实际能力为准。

### 人工使用

开工前读速查卡，做每一步前查阶段说明，需要追溯时读事故档案。用自己的脚本保存规格、配置、日志与复算结果。

## 3. 首次使用：只读验收

```text
我提供了通用手册、精简提示词和论文。
本轮只读，不下载、不安装、不执行代码。
列出可实际访问的文件，定位手册当前阶段，
再核对论文目标实验、预处理、训练协议和指标的出处。
官方代码记录线索与核实状态，不把关键词命中当作可用实现。
文件不可读、参数未声明和运行未验证的部分逐项标注。
```

验收需要看到明确目标、实际可读材料、参数出处，以及区分原文与假设的规格表。仅回答“已理解”不算完成。

如果回答引用不存在的文件，或在只读任务中声称已经训练，先纠正记录。

## 4. 从计划进入执行

示例：

```text
按核对后的规格做一个最小运行。
可执行本地项目代码，在项目专用环境安装列明的依赖。
最多运行10分钟、使用CPU，不启动完整训练。
保留命令、配置、日志；缺数据或超预算时报告实际阻断。
不替换模型或改变评价口径。
```

预算与许可需按真实项目修改，不能照搬到未知外部仓库。没有终端工具时，让 Agent 输出命令与检查点，由你本地运行后提供真实日志；示例输出不能当作执行证据。

## 5. 常见任务边界

| 情况 | 处理方式 |
|---|---|
| 找不到代码 | 记录查找范围，写“本次未找到”，按任务边界决定是否自实现 |
| 链接归属或可用性不明 | `L1-blocked`，保留原因；限定官方仓库时不擅自换路线 |
| 代码可读但未运行 | 标记“运行未验证” |
| 只要求方案 | 不安装、不训练、不运行候选实验 |
| 已授权有限扫描 | 在给定参数集合与预算内推进 |
| 已有具体错误证据 | 先诊断，不强制增加训练预算 |
| 无法区分慢与错 | 授权预算内做单因素诊断，证据不足记“无法判断” |
| 没有外部技能 | 继续按手册执行，C 版不依赖外部技能 |

## 6. 续接与交付

每次结束工作时段留下：

```text
目标：
已读取材料及版本：
实际命令、配置和日志路径：
已验证结果：
未执行或未验证部分：
当前阻断：
剩余授权与预算：
下一步：
```

最终交付包含结论、证据、环境、运行入口、数据获取方式与限制。不要使用历史案例跑分或计划数字替代当前实测结果。

## 7. 更新与边界

手册和精简提示词一起升级，移除资料区中的旧版，防止同一会话读到冲突规则。自己的代码、报告和日志独立保留。

B 与 C 共享方法论来源，但安装契约和修订不同，不要同时加载。C 无技能依赖不代表论文实验无软件、数据或硬件依赖。

情景干跑和规则审查不等于实际论文训练测试。文件读取、代码执行和资料持久化需在你的环境中验收。
