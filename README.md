# 论文复现工作流

用于论文取证、规格拆解、自实现、自证、受控实验与结论核验的工作流。

## 选择版本

| 下载文件 | 使用场景 | 解压后入口 |
|---|---|---|
| [B-DSH版.zip](B-DSH版.zip) | 支持技能加载的 Agent 环境 | `安装说明.md` |
| [C-通用平台版.zip](C-通用平台版.zip) | 通用聊天平台、其他 Agent 或人工使用 | `README-怎么用.md` |

通用版包含完整手册与精简系统提示词，不要求安装外部技能。

## 2026-10-18 更新

- B 版修正代码线索判据、授权边界和必读纪律文件缺失时的处理规则。
- C 版核对代码链接、官方归属、对应实现与运行可行性；关键词命中不直接等于可用官方代码。
- C 版明确已授权实验、仅方案请求和官方仓库限定任务的边界；可选外部技能缺失不阻断。
- C 版将扫描限定在授权参数和预算内，有限扫描不作为全局证明。
- C 版修复预算诊断矛盾：先检查具体错误证据，必要时在授权预算内做单因素诊断。

## 验证范围

通用版由三名独立评审比较修改前后，八个情景干跑通过，最终均建议保留。分发 ZIP 已完成完整性检查及与源文件的逐字节比对。

上述验证属于文本规则审查、情景推演与打包检查，没有重新运行论文训练，不代表实际复现准确率得到验证或保证。
